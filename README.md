Техническое задание на разработку ИС «FinSys2»
1. Общие сведения

Наименование проекта: Сервис мониторинга личных финансов «FinSys2».
Назначение системы: Автоматизация учета доходов и расходов пользователя, визуализация финансовых потоков и управление пользовательским профилем.
2. Технический стек

    Язык программирования: C#.

    Платформа: ASP.NET Core MVC.

    Хранение данных: Локальные JSON-файлы (через сервис JsonDatabase).

    Фронтенд: HTML5, CSS3 (Bootstrap), JavaScript (Chart.js для графиков).

3. Функциональные требования
3.1. Мониторинг транзакций

    Добавление записей о доходах и расходах с указанием суммы, категории и комментария.

    Категоризация операций для последующего анализа.

    Просмотр истории всех финансовых операций.

3.2. Визуализация и аналитика

    Линейная диаграмма: отображение динамики накоплений (баланса) во времени.

    Круговая диаграмма: отображение процентного соотношения категорий расходов и доходов.

    Расчет и вывод текущего общего баланса.

3.3. Управление профилем пользователя

    Регистрация и Аутентификация: создание аккаунта и вход в систему на основе Cookie-авторизации.

    Редактирование данных: возможность изменения ФИО и номера телефона пользователя.

    Безопасность: смена пароля с обязательной проверкой текущего пароля и подтверждением нового.

    Персонализация: загрузка и хранение изображения профиля (аватарки) с использованием IWebHostEnvironment.

4. Требования к интерфейсу

    Навигация: наличие верхней панели (Navbar) со ссылками на «Главную», «Историю» и «Цели».

    Интерактивность: использование модальных окон для авторизации и регистрации.

5. Системные требования и безопасность

    Хранение файлов: загружаемые аватарки сохраняются в директорию wwwroot/avatars с генерацией уникальных имен (GUID) для предотвращения перезаписи.

    Валидация: проверка вводимых данных (длина пароля, формат Email, заполнение обязательных полей).

    Авторизация: разграничение доступа (настройки и финансы доступны только авторизованным пользователям).
